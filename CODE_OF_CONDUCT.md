# Code of Conduct

Be respectful, assume good faith, and keep disagreement technical. Harassment, personal attacks, and discrimination are not tolerated.

Report conduct issues by opening a private security advisory or contacting the maintainer directly (see repository contact info). Reports are handled confidentially.

Based on the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/) — adopt the full text here once the project has more than one active maintainer to enforce it.
